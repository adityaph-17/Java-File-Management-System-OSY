# 📁 Java File Management System (OSY Project)

A Java-based File Management System developed as part of the Operating System (OSY) project.  
This application simulates core file operations such as creation, deletion, reading, writing, and searching within a structured environment.

---

## 📌 Overview

The **Java File Management System** is a mini project designed to demonstrate key concepts of file organization and management in an Operating System.

It allows users to perform essential file operations through an interactive interface, helping in understanding how file systems work internally.

---

## 🎯 Objectives

- Simulate basic file management operations using Java  
- Understand file system organization in an Operating System  
- Provide a simple and user-friendly interface for file handling  

---

## ✨ Features

- Create new files and directories  
- Read and display file contents  
- Write data into files  
- Delete and rename files  
- Search files within directories  
- Display file metadata (size, path, last modified, etc.)  

---

## 🛠 Technologies Used

- **Language:** Java  
- **IDE:** NetBeans / IntelliJ IDEA / Eclipse  
- **Concepts:**  
  - File Handling  
  - I/O Streams  
  - Exception Handling  
  - OS-level File Operations
