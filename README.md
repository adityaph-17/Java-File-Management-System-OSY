# Java-File-Management-System-OSY
A Java-based File Management System developed as part of the Operating System (OSY) project. This application performs core file operations such as creation, deletion, reading, writing, and searching within a simulated environment.

Java File Management System (OSY Project)

Overview

The Java File Management System is a mini project developed for the Operating System (OSY) subject. It demonstrates key concepts of file organization, file operations, and memory management using Java.
The system allows users to perform essential file operations such as creating, reading, writing, deleting, renaming, and searching files through an interactive interface.

⸻

 Objectives
	•	To simulate basic file management operations in Java.
	•	To understand how file systems are organized and managed in an OS.
	•	To provide a simple and user-friendly interface for handling file operations.

⸻

 Features
	•	Create new files and directories
	•	Read and display file contents
	•	Write data into files
	•	Delete or rename files
	•	Search for files in a directory
	•	Display file metadata (size, path, last modified, etc.)

⸻

 Technologies Used
	•	Language: Java
	•	IDE: NetBeans / IntelliJ / Eclipse (any)
	•	Concepts Covered: File Handling, I/O Streams, Exception Handling, and OS-level file operations

   How to Run

  git clone https://github.com/adityaph-17/Java-File-Management-System-OSY.git
